# pairwise-lens-flare

镜头对着太阳时鬼影乱跳、遮挡物边缘漏光、HDR 高光溢出成白块：耀斑位置按屏幕中心；遮挡查询用单点；鬼影序列固定；耀斑强度不随光圈；高光没做阈值；遮挡物透明没有透射；镜头切视野不更新；多个光源叠加爆；耀斑在 UI 上；VR 双眼位置不同步。render/lens_flare.py 是核心，tests/test_lens_flare.py 15个红。要修的是：投影光源位置；多点遮挡；按光圈派生鬼影；强度随光圈；高光阈值；透明透射；视野更新；多光源归一；UI 排除；双眼同步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
